# Маршрутизатор методик

Method router for Claude: from a problem description it picks 3–5 thinking methods out of 92 and writes a pre-idea in each method’s own language. Manufacturing, business processes, products, and public policy. The user chooses a direction; only then is the method expanded into ideas.

Навык не решает задачу сразу. Он сначала называет школу мышления и направление поиска, которое эта школа задаёт. Готовые идеи появляются после того, как человек выбрал номер предидеи.

## Кому это нужно

Инженеру, технологу, продакт-менеджеру или аналитику госпрограммы, у которого задача уже сформулирована, а школа ещё нет. Навык полезен на стыке цеха, процесса, продукта и государственной программы.

Фасилитатору, которому нужен тайминг упражнения на группу, ближе библиотека вроде SessionLab. Инженеру, который уже назвал техническое противоречие и хочет матрицу 39×39, ближе одношкольный решатель ТРИЗ.

## Что делает навык

1. **Маршрутизация.** Диагноз, 3–5 методов с разными углами зрения, предидея A1…A5 на языке метода, первый шаг на 30–60 минут.
2. **Углубление.** Человек называет номер, навык проходит алгоритм выбранной карточки и доводит его до идей.
3. **Сравнение.** По запросу сопоставляет два уже предложенных метода на той же задаче.
4. **Продолжение.** После углубления предлагает следующий метод из каталога.

Каталог — 92 метода в 13 школах: ТРИЗ, теория ограничений, Lean и качество, управление изменениями, процессы, продукт и клиент, креативные техники, SIT, стратегия и форсайт, госполитика, выбор решений, институты и стимулы, данные и модели. У каждой карточки есть стадия, отрасли, «когда применять», «когда не подходит», алгоритм, пример и сочетания.

Методы про стимулы (`principal-agent`, `game-theory`, `mechanism-design`) берутся только если в описании прямо виден оппортунизм: обход правил, поборы, приписки, формальная отчётность, выгода исполнителя от поведения, которое вредит цели. Брейнрайтинг и SCAMPER стоят последними, когда нет более точного сигнала.

Номера приёмов и параметров ТРИЗ берутся из `references/triz.md`.

## Чего навык не делает

Он не заменяет матрицу Альтшуллера, карту потока ценности или сводный отчёт по оценке регулирующего воздействия. Предидея — направление поиска, а не решение. Навык может выбрать чужую школу: пауза на предидеях для того и сделана, чтобы человек успел выбросить направление.

## Как поставить навык

Для работы нужны три файла: `SKILL.md`, `references/methods.md` и `references/triz.md`. Папка `evals/` и статья пользователю не нужны.

### Claude Code

Склонируйте репозиторий в каталог навыков. На macOS и Linux:

```bash
git clone https://github.com/sadmae/method-router ~/.claude/skills/method-router
```

На Windows в PowerShell:

```powershell
git clone https://github.com/sadmae/method-router "$env:USERPROFILE\.claude\skills\method-router"
```

Чтобы навык работал только в одном проекте, клонируйте его в `.claude/skills/method-router` внутри этого проекта.

### Claude.ai и приложение Claude

1. Скачайте `method-router.zip` со страницы [последнего релиза](https://github.com/sadmae/method-router/releases/latest).
2. Откройте настройки Claude, раздел с навыками (Skills).
3. Загрузите архив и включите навык.

Навыки доступны на тарифах, где включено выполнение кода.

### Другие ИИ: ChatGPT, Gemini и прочие

Формата навыков там нет, но файлы — обычный текст. Создайте проект или собственного ассистента, вставьте содержимое `SKILL.md` в инструкции, а `references/methods.md` и `references/triz.md` приложите как файлы знаний. Навык проверяли только в Claude; в других моделях результат может отличаться.

### Как пользоваться

Опишите проблему обычным текстом или вызовите навык по имени `method-router`. Если данных мало, навык задаёт не больше трёх вопросов, и только таких, ответ на которые меняет метод. Если данных достаточно, он пишет допущения и сразу даёт предидеи.

Выберите номер, например «A2», чтобы развернуть метод.

## Проверка

На 13 авторских задачах навык прогоняли дважды, отдельными сессиями Claude, без доступа к файлу с ожидаемыми методами. После первого прогона в инструкцию добавили запрет брать методы про стимулы без явного сигнала. На втором прогоне лишние методы этой школы ушли с 6 ответов из 13 до нуля среди 10 полученных ответов. Одна задача из десяти не закрыла вторую обязательную группу методов. Три ответа второго прогона не получены из‑за лимита модели.

Ожидаемые методы задавал автор навыка. Внешней проверки на чужих задачах нет.
